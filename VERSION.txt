SYNERGOX SITE — BUILD 12  (Supabase restored — Formspree removed)
=================================================================

WHY THIS BUILD
  Formspree's autoresponse (needed to email the book) is a PAID feature,
  so it isn't free for this use. Supabase does storage + book email on
  its FREE tier. This build puts Supabase back and removes Formspree.

WHAT CHANGED FROM THE FORMSPREE BUILD
  - All three forms (opt-in, checklist, apply) now call the Supabase
    `subscribe` Edge Function again — saves the lead to a `leads` table
    AND emails the book via Resend. Apply's answers go in a `meta` JSON.
  - The Paystack pay button verifies the payment SERVER-SIDE via the
    `verify-payment` Edge Function before marking paid / sending to /guide
    (rejects underpayment).
  - Restored: supabase/functions/subscribe, supabase/functions/verify-payment,
    supabase/migrations/0001_leads.sql.
  - lib/site.ts now holds Supabase URL + anon key (both browser-safe,
    paste-in-file, no redeploy trap) instead of a Formspree endpoint.

KEPT FROM BEFORE (all the good fixes)
  - Every conversion CTA -> opt-in -> /offer (payment page). Only /learn
    goes to book-a-call (/apply).
  - Paystack public key is paste-in-file in lib/site.ts (avoids the
    "checkout being set up" env-var/redeploy trap). Clear error messages
    + browser-console diagnostics if the key is missing.
  - Conversion-focused /offer page (hero, problem, 6 deliverables,
    "this is / isn't for you", value stack ₦199,999 vs ₦2.45M+, scarcity,
    risk reversal, real proof, objections, close). Paystack button x3.
  - Price ₦199,999 = 19999900 kobo.
