** YOUR "supabaseUrl is required" ERROR — HOW TO FIX IT **  (see FIX_LEADS.txt)
   That error means the deployed subscribe function got an EMPTY project URL,
   so createClient crashed and the function shut down before saving — which is
   why the leads table stayed empty.
   CAUSE: Supabase reserves the SUPABASE_ prefix, so SUPABASE_URL /
   SUPABASE_SERVICE_ROLE_KEY weren't reaching your function.
   FIX (this build already reads non-reserved names):
     1. Set two secrets:
          supabase secrets set PROJECT_URL=https://YOURPROJECT.supabase.co
          supabase secrets set SERVICE_ROLE_KEY=<your service_role key>
        (service_role key = Supabase > Settings > API > service_role. NOT anon.)
     2. Redeploy:  supabase functions deploy subscribe
                   supabase functions deploy verify-payment
     3. Make sure the table exists: run supabase/migrations/0001_leads.sql
   The function now also returns a clear config/database error instead of
   crashing, so if anything's still off you'll see the reason in the Network
   tab and the function logs. Full walkthrough + curl test in FIX_LEADS.txt.
