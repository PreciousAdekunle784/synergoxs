SYNERGOX SITE — BUILD 18
========================

ADMIN DASHBOARD, CONTENT MANAGEMENT, ANIMATION (this build)

  ADMIN DASHBOARD — /admin            (setup: ADMIN_SETUP.txt)
    Overview        Visitors, leads, bookings, new inquiries, conversion
                    rate, per-day charts, pipeline, sources, latest
                    submissions, recent activity. Real data only.
    Leads           Search, filter, sort; per-lead status, notes, delete.
    Consultations   Every booking-form submission and whether it became a
                    booked call; status, call time, notes.
    Website content Headlines and copy, services, case studies,
                    testimonials, contact details and links. Live on save.
    Settings        Password, who can sign in, what is connected.

    Secured with Supabase Auth, httpOnly session cookies, a middleware
    guard, and database functions that each check admin rights. Every
    table has row level security on with no policies.
